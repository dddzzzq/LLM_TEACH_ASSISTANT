---
name: fetch-homework
description: 在现有任务浏览器完成已保存账号的登录认证，或定位指定课程与作业并打开附件导出；使用原页面 Agent，不创建独立流程。
---

此 Skill 为页面导航 Agent 提供西电教学平台的业务操作知识。输入为目标课程、作业名称、可选学期、当前阶段和页面观察。它不创建后台任务、不注册工具，也不定义动作参数协议。

有 authentication.credentials_saved 时，先观察当前认证页面：login_form 为 true 且 credentials_filled 为 false，调用 fill_portal_credentials，由 Worker 内部读取已保存账号密码并提交。需要验证码时调用 request_login_code，教师在原任务浏览器填写后交还自动化，再调用 submit_login_code；已获取但未填写或填写无效时请求本人输入。trust_prompt 为 true 时用 apply_device_trust，按教师设置选择信任设备。无已保存凭据时保留原人工登录。密码和验证码不经过聊天或模型参数。

credentials_filled 为 true 后，不再调用 fill_portal_credentials。根据当前页面继续认证；官网显示中英文验证码错误时，不通过重复填写或滚动尝试恢复。账号填写动作会等待官网异步验证检查完成，再提交登录，后续继续复用原验证工具。

首次连接任务（task_type=AUTH_BOOTSTRAP）只完成认证，由执行器核验后结束；不要继续下载。正常下载继续原业务流程。任务控制器根据已选官网班级范围处理导出提交、导出关联及文件传输。

target.portal 存在时，根据课程、班级及作业的官网 ID 结合 platform_ids 区分同名记录。只选择匹配 ID 的当前页面入口，不构造直达地址，不用相同名称替换另一条官网记录。没有 ID 的原任务保留名称匹配和教师确认。

旧卡片可能只暴露名称和脚本入口。可以按目标名称、学期与上下文进入该只读页面，由执行器核验跳转后的官网 ID；进入页面本身不等于已确认课程/作业，不能跳过后续 ID 核验而导出附件。

SOLVE_CAPTCHA 阶段：先读取 observation.captcha。仅当 visible=true 且 attempts_remaining>0 时调用无参数的 solve_slider_captcha；存在歧义或需要其他验证时使用 request_human。该阶段不使用 click、fill、scroll 或页面切换操作验证码，不提取图片、不生成拖动轨迹、不索取账号密码。本轮总尝试次数由执行器限制为三次，失败后交给用户，不能反复调用或恢复任务绕过预算。人工控制期间不自动处理。滑块消失仅说明挑战可能完成，完整登录状态以执行器核验为准；登录核验通过后沿现有页面继续定位课程和作业。

先阅读完整页面基础信息，再按下面的业务目标推进。门户→个人空间→课程→作业菜单→指定作业批阅入口→更多菜单→导出作业附件是业务流程；按钮样式、CSS 类名、DOM 层级及菜单位置可以变化。

每步先查看 pages 和 frames 的标题、URL 路径、标题层级与导航分区，再查看 elements 的语义角色、可访问名称、局部上下文及 context_labels，判断当前页面已经完成哪些业务步骤。结合 target_evidence 的核验结果选择下一步。已处于课程或作业详情时从当前位置继续，不回到门户重走流程。
`active_page_id` 标明当前页，frames/elements 聚焦该页，其他标签只保留 pages 摘要。点击个人空间等入口打开新页后，在新页继续；需要复用已有课程页时先 switch_page，不重复点击门户入口创建相同标签页。

1. 定位课程入口：根据“个人空间”“我的课程”“课程”等实际可见控件进入课程区域。优先观察当前页面是否已经展示课程列表或目标课程标题。
2. LOCATE_COURSE：先完成“门户→个人空间→课程列表”的原导航。阶段名称不代表当前页面已经是课程列表；门户菜单、个人空间入口不是课程候选，不要在这些入口比较课程名或请求教师确认。到达实际列表后，由大模型根据页面课程名、学期和同一卡片上下文判断：准确匹配直接继续；没有准确匹配时，可以判断可信的近似名称、少量错字，用 request_target_confirmation 请求教师弹窗确认。element_ref 引用候选名称或同一卡片的入口，actual_name 必须是该控件 name 或 context_labels 中的原文；kind=course，reason 说明差异，term 填当前页面实际学期，页面无学期证据可传空字符串。教师确认后 target 自动更新，继续原流程，不重复确认。
   只查页面当前已选学期。课程列表已查看完整（含必要搜索或分页）仍没有可信匹配时，立即 request_human 弹窗提醒“当前页面未找到目标课程，请确认课程名或学期”。不自动展开学期菜单、选择第二学期或其他学期，不用 click/fill 操作学期控件。用户指定学期与页面当前学期不同也请教师手动核查或切换。教师处理完并点击“交还自动化”后，从当前页面继续原流程。
3. LOCATE_ASSIGNMENT：进入原有作业菜单，根据作业名称和同一条记录上下文，优先点击该作业行的“批阅”“评阅”或“查看提交”。作业名称和“查看”常打开题目预览，不与批阅入口等价，不要为了拉取学生附件反复点击作业名称。已进入只显示题目、答案区的预览页且没有学生列表或导出入口时，返回原作业列表，再点击目标行的批阅入口；不要在多个题目预览标签之间循环切换。页面标题即使叫“作业详情”，只要显示学生提交列表和“更多/导出附件”，就沿当前页继续导出。准确匹配直接继续；没有准确匹配时，结合页面含义寻找可信近似名称，例如“作业1 / 作业一”“第1次作业 / 第一次作业”，用 request_target_confirmation（kind=assignment）请教师确认原名和实际名称，确认后按更新后的 target 继续。不同编号不能互相推荐。没有可信候选时提醒教师核查作业名。不得直接进入未经教师确认的其他名称作业。本 Skill 不负责读取和总结题目要求，不调用 read_homework_detail。
4. EXPORT：核对当前作业后，依据“更多 / More → 导出作业附件 / 导出附件 / Export homework”等真实控件进入导出设置。can_open_export=true 时优先调用 open_export_settings，执行器会在菜单关闭时展开唯一的“更多 / More”，菜单已展开时直接继续，不能反复点击将其关上。中英文文案均可能出现，不点击“导出成绩 / Export grades”。单班级任务由执行器按真实班级 ID 切换并重新核验导出入口，禁止为了继续流程改选全部班级。设置打开后由任务控制器处理班级和提交。部分作业弹窗只有导出格式与命名格式，沿用批阅页当前班级，不会另列班级范围；不能仅因弹窗没有班级控件就请求人工。执行器核验目标班级 ID，尚未选中时先关闭未提交设置、切到目标班级再重新打开。下载中心的“暂无可下载内容 / No downloads”是有效空状态，不代表班级未选或作业没有附件；是否有学生附件由提交导出后的官网结果判断。导出确认、下载及重复提交保护仍由执行器负责，不使用通用点击绕过。

coverage.truncated 表示模型观察经过长度控制，不表示页面不存在目标。优先使用已观察到的搜索框、滚动和页面切换补充信息。不得猜测未展示的 element_ref。控件 disabled 时不点击。frame_id 和 page_id 可用于区分 iframe、弹窗及新标签页。
学期控件和选项仅供读取当前页面信息及人工操作，不属于自动操作范围；即使菜单已展开也不点击其中选项。
在课程列表查找时，结合 frames 的 scroll/viewport、可见分页和列表上下文判断是否已查看完整：已到列表末尾，或文档高度不超过视口且观察未截断时，不要重复滚动。当前页面确无可信目标就提醒教师确认课程名或学期。

element_ref 只对当前观察有效。一次只推进一个动作，每次动作后重新观察页面基础信息，并按整个业务流程更新当前阶段。优先选择与目标名称精确对应的控件；context 和 context_labels 是控件局部的业务信息。不要仅因页面外观或类名变化请求人工；确实无法消歧、缺少目标核验或无明确进展时再交接。
减少重复交接：target_evidence 已确认的课程和作业直接沿当前流程继续。recent_actions 出现暂时失败或 unknown 时，先核对当前观察是否已到达目标，再选择其他可验证的导航入口；不重放旧动作，也不因一次超时立即请求人工。不要把班级勾选或附件选项异常解释为“需要再次确认当前作业”。相同按钮若确实翻页或使页面内容改变，属于有效进展。
进入导出设置即完成当前导航阶段。target.portal.class_id 存在时，必须由任务控制器按该官网班级 ID 导出，不得扩大为全部班级，也不再请求教师重复选择；class_id 为空的明确全部班级任务沿用全部班级范围。不要声称文件已下载，完成状态以执行器核验为准。没有明确进展、遇到歧义、滑块处理失败或其他认证挑战时请求人工操作。
